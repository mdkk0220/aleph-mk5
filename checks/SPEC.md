# 고정 검사 10개 (T05 과제) — 작업 시작 전 확정본
확정 시각: 2026-10-20 11:59 KST 이전. 이후 삭제·완화·기대값 변경 금지.
대상 화면: 탭 "4. 실제 템플릿 관리". 개선 목표: 새로고침해도 템플릿이 남는다.

| ID  | 입력 | 관찰 가능한 기대값 |
|-----|------|--------------------|
| T01 | 이름 "A"로 '현재 설정 저장' | 목록에 "A"가 보이고 "템플릿 저장에 실패했어요" 문구가 없음 |
| T02 | 이름을 비우고 저장 | 목록에 "템플릿 1"이 보임 |
| T03 | "A" 저장 후 새로고침 | 목록에 "A"가 남아 있음 |
| T04 | "A","B" 순서로 저장 후 새로고침 | 목록에 A, B가 이 순서로 2개 |
| T05 | 문구 "안녕", 가로 10, 크기 9, 색 #ff0000, 비율 4:5로 저장 → 설정을 바꿈 → 불러오기 | 문구·가로·크기·색·비율이 저장 당시 값으로 돌아옴 |
| T06 | A, B 저장 → A 삭제 → 새로고침 | 목록에 B만 있음 |
| T07 | 문구를 비운 채 저장 | 목록 항목에 "(빈 문구)"가 보임 |
| T08 | 이름에 공백만 입력하고 저장 | 목록에 "템플릿 1"이 보임 |
| T09 | 크기 2로 저장(이름 "min"), 크기 20으로 저장(이름 "max") → 각각 불러오기 | 슬라이더 표시가 "희망 크기 2%", "희망 크기 20%" |
| T10 | 저장소 키 photo-editor-templates 값을 깨진 JSON으로 두고 새로고침 | 빈 목록 안내가 보이고 화면이 정상 표시됨 |
